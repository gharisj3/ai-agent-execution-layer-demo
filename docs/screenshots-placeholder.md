# Screenshot Guide

No screenshots are currently committed. Do not add mock or fabricated UI images.

For a README or portfolio post, capture these from a running local demo and save them under `docs/screenshots/` with descriptive names:

1. `n8n-workflow-overview.png` — full extraction, decision, approval, execution, and audit flow
2. `allowed-inventory-response.png` — `allowed` guardrail response
3. `approval-required-payment.png` — high-value payment decision
4. `blocked-inactive-vendor.png` — inactive-vendor rejection
5. `audit-events-response.png` — request, decision, approval status, and mock result
6. `fastapi-docs.png` — optional Swagger UI overview

Before committing, check that screenshots contain no API keys, cookies, tokens, personal data, browser profiles, local filesystem paths, or unrelated tabs.
