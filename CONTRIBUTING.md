# Contributing

Focused improvements are welcome.

1. Fork the repository and create a descriptive branch.
2. Keep changes scoped to the execution-layer demo.
3. Do not commit credentials, real business data, or generated databases.
4. Install dependencies with `python -m pip install -r requirements.txt`.
5. Run `python -m pytest -v`.
6. Open a pull request explaining the behavior changed and verification performed.

Please preserve the core boundary: AI proposes intent; deterministic controls authorize execution.
